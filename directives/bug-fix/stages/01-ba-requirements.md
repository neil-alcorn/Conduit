# Stage 1 — BA Requirements (Bug Fix)

**Stage 1 is skipped for bug-fix convoys.**

Bug-fix convoys proceed directly from Stage 0 (Intake) to Stage 3 (Implementation).
Root cause analysis and fix approach are captured at Stage 0 instead.

See `directives/net-new/stages/01-ba-requirements.md` for reference on what this stage covers in net-new convoys.
